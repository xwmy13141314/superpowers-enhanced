# Competitive Analysis - 竞品分析技能

**当以下情况时使用此 Skill**：
- 需要分析竞争对手
- 寻找差异化定位
- 用户询问"竞品怎么样"、"如何差异化"

## 核心原则

**知己知彼，差异化竞争**

## 工作流程

### 阶段 1: 竞品识别
- 识别直接竞品
- 识别间接竞品
- 识别潜在竞品

### 阶段 2: 竞品对比
- 功能对比
- 价格对比
- 用户体验对比

### 阶段 3: SWOT 分析
- 优势
- 劣势
- 机会
- 威胁

### 阶段 4: 差异化策略
- 垂直化
- 本地化
- 企业化

### 阶段 5: 竞品分析报告
- 创建飞书文档
- 呈现关键发现

## 输出模板

### 竞品分析报告

1. 竞品列表
2. 竞品对比矩阵
3. SWOT 分析
4. 差异化建议
