# Technical Design - 技术设计技能

**当以下情况时使用此 Skill**：
- 设计系统架构
- 设计数据库
- 设计 API
- 用户说"技术设计"、"架构设计"

## 核心原则

**架构合理，技术可行**

## 工作流程

### 1. 系统架构设计
- 分层架构（表现层、业务层、数据层）
- 服务划分
- 技术选型

### 2. 数据库设计
- ER 图
- 表结构
- 索引设计
- 数据字典

### 3. API 设计
- RESTful 设计
- 接口定义
- 请求/响应格式
- 错误码

### 4. 技术选型
- 前端框架
- 后端框架
- 数据库
- 中间件

## 输出

- 技术设计文档
- 系统架构图
- 数据库设计文档
- API 文档
