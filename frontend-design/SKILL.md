# Frontend Design - 前端设计技能

**当以下情况时使用此 Skill**：
- 用户要求设计 UI/UX 界面
- 需要创建网页、应用界面
- 涉及视觉设计、布局、交互设计
- 需要呈现设计稿或原型

## 核心原则

**视觉化优先 > 文字描述**

- 能用图展示的，不用文字描述
- 先呈现视觉效果，再讨论细节
- 提供多个设计选项供选择

## 触发条件

当用户表达以下意图时自动触发：
- "设计一个...界面"
- "做个...的 UI"
- "帮我画个...原型"
- "这个页面应该怎么布局"
- 任何涉及视觉设计的请求

## 流程

### 1. 理解设计需求

**澄清问题（一次一个）：**
- 目标用户是谁？
- 主要使用场景？
- 需要支持哪些设备（桌面/移动/平板）？
- 有品牌规范吗（颜色、字体、logo）？
- 有参考设计或竞品吗？

### 2. 收集设计素材

**需要确认：**
- 配色方案（提供选项）
- 字体偏好
- 设计风格（现代/经典/极简/活泼）
- 必要元素（logo、导航、按钮等）

### 3. 创建设计方案

**使用 Canvas 呈现：**
- 线框图（Wireframe）
- 布局草图
- 配色方案展示
- 交互流程图

**输出内容：**
```
1. 整体布局图
2. 关键组件设计
3. 配色方案
4. 字体方案
5. 响应式适配说明
```

### 4. 提供设计选项

**至少提供 2-3 个方案：**
- 方案 A: [风格描述]
- 方案 B: [风格描述]
- 方案 C: [风格描述]

每个方案包含：
- 视觉预览
- 优缺点
- 适用场景

### 5. 用户选择与调整

**等待用户反馈：**
- 哪个方案更喜欢？
- 需要调整什么元素？
- 颜色/布局/字体是否满意？

根据反馈调整设计，直到用户满意。

### 6. 输出设计文档

**设计文档包含：**
```markdown
# [项目名称] 设计文档

## 1. 设计概述
- 目标用户
- 使用场景
- 设计风格

## 2. 视觉规范
### 2.1 配色方案
- 主色：#XXXXXX
- 辅助色：#XXXXXX
- 强调色：#XXXXXX
- 背景色：#XXXXXX
- 文字色：#XXXXXX

### 2.2 字体方案
- 标题字体：[字体名]
- 正文字体：[字体名]
- 字号规范：[h1-h6, body]

## 3. 布局设计
### 3.1 桌面端布局
[布局图/说明]

### 3.2 移动端布局
[布局图/说明]

## 4. 组件设计
### 4.1 导航栏
[设计说明]

### 4.2 按钮
[设计说明]

### 4.3 卡片
[设计说明]

## 5. 交互说明
- 点击效果
- 悬停效果
- 过渡动画

## 6. 响应式断点
- 桌面：≥1200px
- 平板：768px-1199px
- 手机：≤767px
```

### 7. 过渡到实现

设计批准后：
- 调用 `writing-plans` 技能创建实现计划
- 或直接开始编码（如果用户要求）

## 设计原则

### 1. 一致性
- 颜色使用一致
- 字体层级清晰
- 间距统一（使用 4/8px 倍数）

### 2. 可读性
- 文字对比度足够（WCAG AA 标准）
- 行高适当（1.5-1.8）
- 段落长度适中

### 3. 可用性
- 按钮大小适合点击（≥44px）
- 交互反馈明确
- 错误状态清晰

### 4. 响应式
- 移动优先设计
- 断点合理
- 内容自适应

## 反模式警示

**永远不要：**
- ❌ 直接写代码，不先呈现设计
- ❌ 只提供文字描述，没有视觉稿
- ❌ 不考虑响应式适配
- ❌ 忽略可访问性（对比度、字体大小）

**正确做法：**
- ✅ 先展示设计稿，再讨论实现
- ✅ 提供多个方案供选择
- ✅ 考虑多设备适配
- ✅ 遵循设计规范和最佳实践
