# Market Research - 市场调研技能

**当以下情况时使用此 Skill**：

- 用户提出新产品概念或想法
- 需要了解市场规模、增长趋势、行业动态
- 需要分析目标市场、市场细分、市场机会
- 需要评估产品可行性、商业潜力
- 用户询问"这个市场怎么样"、"有多少机会"等问题

## 核心原则

**数据驱动的市场洞察 > 主观臆断**

在做出任何产品决策之前，必须基于市场数据进行客观分析。市场调研是产品开发的基石，决定了产品方向和商业潜力。

## 工作流程

### 阶段 1: 市场概况分析

#### 1.1 市场规模分析

**收集以下数据：**

- **TAM (Total Addressable Market)** - 总体可寻址市场
  - 全球市场规模
  - 市场价值（亿美元）
  - 增长率（CAGR）

- **SAM (Serviceable Addressable Market)** - 可服务市场
  - 目标地理区域市场
  - 可触达的用户群体
  - 技术可达性

- **SOM (Serviceable Obtainable Market)** - 可获得市场
  - 初期可获得的市场份额
  - 竞争环境下的实际可达市场
  - 资源约束下的市场范围

**数据来源：**
- 行业报告（Gartner, Forrester, IDC）
- 市场研究数据库（Statista, Euromonitor）
- 投资机构报告
- 新闻报道和公开数据

#### 1.2 市场增长趋势

**分析维度：**

- **历史增长** - 过去 5-10 年的市场增长
- **当前状态** - 市场成熟度（萌芽/成长/成熟/衰退）
- **未来预测** - 未来 3-5 年的增长预测
- **驱动因素** - 推动市场增长的关键因素
- **阻碍因素** - 可能阻碍市场发展的因素

**关键指标：**
- 年复合增长率 (CAGR)
- 市场渗透率
- 用户增长率
- 收入增长率

#### 1.3 行业动态分析

**分析内容：**

- **技术趋势** - 相关技术发展动向
- **政策法规** - 政府政策、法规变化
- **资本流动** - 投融资活跃度
- **并购活动** - 行业整合趋势
- **新兴玩家** - 新进入者、颠覆者

### 阶段 2: 目标市场分析

#### 2.1 市场细分

**细分维度：**

- **地理细分**
  - 国家/地区
  - 城市/农村
  - 气候区域

- **人口统计细分**
  - 年龄、性别、收入
  - 教育水平、职业
  - 家庭结构

- **心理细分**
  - 生活方式、价值观
  - 兴趣爱好、个性特征

- **行为细分**
  - 使用频率、使用场景
  - 品牌忠诚度、购买意愿
  - 价格敏感度

#### 2.2 目标市场选择

**评估标准：**

- 市场规模和增长潜力
- 竞争强度
- 与产品能力匹配度
- 进入壁垒
- 盈利能力

**输出：**
- 明确定义目标市场
- 目标用户画像
- 市场优先级排序

### 阶段 3: 竞争格局分析

**分析内容：**

- 直接竞争对手数量和规模
- 间接竞争对手
- 市场集中度（CR4, CR8）
- 竞争强度评估
- 市场进入壁垒

### 阶段 4: 机会与威胁分析

**市场机会：**
- 未满足的需求
- 服务不足的细分市场
- 技术创新机会
- 政策红利

**市场威胁：**
- 替代品威胁
- 价格战风险
- 政策风险
- 技术颠覆

### 阶段 5: 市场调研报告

**创建飞书文档，包含：**

1. **执行摘要** - 关键发现和建议
2. **市场规模** - TAM/SAM/SOM 分析
3. **增长趋势** - 历史和预测数据
4. **行业动态** - 技术、政策、资本趋势
5. **目标市场** - 细分和选择
6. **竞争格局** - 竞争对手分析
7. **机会威胁** - SWOT 分析
8. **数据来源** - 引用和参考文献
9. **附录** - 原始数据、图表

## 使用方法

### 触发示例

```
用户：我想做一个 AI 写作助手
用户：这个市场怎么样？有多大？
用户：帮我分析一下跨境电商市场
用户：这个产品有商业潜力吗？
```

### Agent 响应流程

```
1. 确认调研目标
   - 明确产品概念
   - 确定调研范围

2. 执行市场调研
   - 搜索行业报告
   - 收集市场数据
   - 分析竞争格局

3. 创建调研报告
   - 生成飞书文档
   - 呈现关键发现
   - 提供行动建议
```

使用 `multi-search-engine` 技能搜索：

```python

```

### 数据分析

使用 `tencent-docs` 或飞书表格分析数据：

```python

# 录入市场数据

        "市场规模": "100亿美元",
```

## 质量标准

### 调研质量检查

完成市场调研后，必须验证：

- [ ] 数据来源可靠（权威机构、官方数据）
- [ ] 数据时效性（最近 12 个月内）
- [ ] 数据一致性（多源交叉验证）
- [ ] 分析完整性（覆盖所有关键维度）
- [ ] 结论客观性（基于数据而非主观判断）

### 常见错误

❌ **避免：**
- 使用过时数据（超过 2 年）
- 只找一个数据源
- 混淆相关性和因果性
- 忽视市场细分
- 高估市场规模

✅ **应该：**
- 多源交叉验证
- 使用最新数据
- 明确数据假设
- 细分市场分析
- 保守估计

### 输入到这些技能

- market-research 的输出 → competitive-analysis 的输入
- market-research 的输出 → product-strategy 的输入
- 目标市场定义 → user-research 的范围
