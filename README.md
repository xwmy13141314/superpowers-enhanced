## 🎯 核心理念

**从创意到交付的完整产品开发工作流**

这套增强版技能包提供端到端的产品开发流程，覆盖：

- **产品阶段**：市场调研、需求分析、竞品分析、用户研究
- **创意阶段**：创意生成、创意筛选、创意验证
- **设计阶段**：产品设计、UI/UX 设计、交互设计
- **开发阶段**：技术设计、编码实现、测试驱动
- **质量阶段**：代码评审、系统测试、性能优化
- **运营阶段**：数据分析、用户反馈、持续迭代

**核心理念：系统化产品开发 > 临时功能实现**

## 📦 技能包结构

### 🎨 产品层（Product Layer）- 5个技能

| 技能 | 触发时机 | 核心作用 |
|------|---------|---------|
| **market-research** | 产品立项、市场分析 | 市场调研、行业分析、趋势洞察 |
| **requirement-analysis** | 需求收集、需求梳理 | 需求分析、用户故事、优先级排序 |
| **competitive-analysis** | 竞品分析、差异化定位 | 竞品分析、SWOT 分析、差异化策略 |
| **user-research** | 用户研究、用户画像 | 用户访谈、用户画像、用户旅程 |
| **product-strategy** | 产品战略、路线图 | 产品定位、战略规划、路线图设计 |

### 💡 创意层（Ideation Layer）- 3个技能

| 技能 | 触发时机 | 核心作用 |
|------|---------|---------|
| **idea-generation** | 创意头脑风暴 | 创意生成、思维发散、创意组合 |
| **idea-validation** | 创意验证 | 可行性分析、MVP 设计、假设验证 |
| **brainstorming** | 方案设计 | 技术方案设计、架构设计、技术选型 |

### 🎨 设计层（Design Layer）- 3个技能

| 技能 | 触发时机 | 核心作用 |
|------|---------|---------|
| **product-design** | 产品设计 | 功能设计、信息架构、流程设计 |
| **frontend-design** | UI/UX 设计 | 界面设计、交互设计、视觉呈现 |
| **technical-design** | 技术设计 | 系统架构、数据库设计、API 设计 |

### 🛠️ 开发层（Development Layer）- 4个技能

| 技能 | 触发时机 | 核心作用 |

## 🎯 核心原则

### 产品原则
1. **用户中心** — 一切从用户需求出发
2. **数据驱动** — 决策基于数据而非猜测
3. **快速验证** — 小步快跑，持续验证
4. **价值优先** — 专注高价值功能

### 开发原则
1. **设计优先** — 没有批准的设计，不写实现代码
2. **测试先行** — 没有失败的测试，不写生产代码
3. **根本原因** — 没有调查，不提出修复
4. **早期评审** — 每个任务后评审，捕获问题

### 质量原则
1. **质量内建** — 质量是每个人的责任
2. **持续改进** — 每个迭代都优于前一个
3. **安全第一** — 安全不是事后考虑
4. **性能为王** — 性能是用户体验的基础

## 🛠️ 与 OpenClaw 集成

### 飞书文档集成

所有文档自动创建为飞书云文档：

```python
feishu_doc(
    action="create",
    title="[产品] 市场调研报告",
    content=markdown_content,
    grant_to_requester=True
)
```

### Canvas 设计展示

UI/UX 设计使用 Canvas 实时展示：

```python
canvas(
    action="present",
    url="design_mockup.html"
)
```

### 子代理并行开发

大型项目使用子代理并行开发：

```python
sessions_spawn(
    runtime="subagent",
    task="实现用户认证模块",
    mode="session"
)
```

### 数据分析集成

使用智能表格进行数据分析：

```python
feishu_bitable_list_records(
    app_token="...",
    table_id="..."
)
```
