# User Research - 用户研究技能

**当以下情况时使用此 Skill**：
- 需要了解目标用户
- 创建用户画像
- 分析用户旅程
- 用户说"了解一下用户"、"用户研究"

## 核心原则

**用户中心，深度理解**

## 工作流程

### 1. 用户访谈
- 访谈提纲设计
- 一对一访谈（30-60 分钟）
- 录音和笔记

### 2. 用户画像
- 基本信息（年龄、职业、收入）
- 行为特征
- 痛点和需求
- 目标和动机

### 3. 用户旅程地图
- 触发点
- 接触点
- 痛点
- 机会点

### 4. 痛点分析
- 主要痛点
- 痛点优先级
- 解决方案

## 输出

- 用户研究报告
- 用户画像（3-5 个）
- 用户旅程地图
- 痛点清单
