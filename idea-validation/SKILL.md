# Idea Validation - 创意验证技能

**当以下情况时使用此 Skill**：
- 验证创意可行性
- 设计 MVP
- 测试假设
- 用户说"验证这个想法"、"可行吗"

## 核心原则

**快速验证，低成本试错**

## 工作流程

### 1. 假设定义
- 核心假设
- 风险假设

### 2. 可行性分析
- 技术可行性（技术栈、资源）
- 商业可行性（市场、收入）
- 用户可行性（需求、接受度）

### 3. MVP 设计
- 核心功能（3-5 个）
- 最简可行产品
- 验证指标

### 4. 验证计划
- 验证方法（访谈、问卷、测试）
- 验证周期（1-2 周）
- 成功标准

## 输出

- 可行性分析报告
- MVP 方案
- 验证计划
