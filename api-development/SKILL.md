# API Development - API 开发技能

**当以下情况时使用此 Skill**：
- 开发 RESTful API
- 开发 GraphQL API
- 编写 API 文档
- 用户说"开发 API"、"接口开发"

## 核心原则

**接口优先，文档齐全**

## 工作流程

### 1. API 设计
- RESTful 规范
- URL 设计
- 方法选择（GET/POST/PUT/DELETE）
- 状态码

### 2. API 实现
- 框架选择（FastAPI、Express）
- 中间件
- 错误处理
- 日志记录

### 3. API 测试
- 单元测试
- 集成测试
- 性能测试

### 4. API 文档
- Swagger/OpenAPI
- 接口说明
- 示例代码

## 输出

- API 接口
- API 文档（Swagger）
- 测试用例
