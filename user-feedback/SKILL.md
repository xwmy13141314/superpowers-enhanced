# User Feedback - 用户反馈技能

**当以下情况时使用此 Skill**：
- 收集用户反馈
- 分析用户反馈
- 处理用户反馈
- 用户说"用户反馈"、"反馈分析"

## 核心原则

**倾听用户，持续改进**

## 工作流程

### 1. 反馈收集
- 应用内反馈
- 问卷调研
- 客服反馈
- 社交媒体监听

### 2. 反馈分类
- 功能请求
- Bug 报告
- 性能问题
- 体验问题

### 3. 反馈分析
- 频次统计
- 优先级排序
- 趋势分析
- 根因分析

### 4. 反馈处理
- 确认收到
- 评估优先级
- 安排修复
- 通知用户

## 输出

- 用户反馈报告
- 高频问题清单
- 改进建议
