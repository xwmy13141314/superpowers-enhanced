# Continuous Iteration - 持续迭代技能

**当以下情况时使用此 Skill**：
- 规划迭代
- A/B 测试
- 功能优化
- 用户说"迭代"、"A/B 测试"

## 核心原则

**小步快跑，持续改进**

## 工作流程

### 1. 迭代规划
- 迭代目标
- 功能优先级
- 资源分配
- 时间规划

### 2. A/B 测试设计
- 假设定义
- 变量设计
- 样本量计算
- 测试周期

### 3. 功能优化
- 数据驱动优化
- 用户反馈驱动
- 技术债务偿还

### 4. 效果验证
- 关键指标对比
- 统计显著性检验
- 结论和建议

## 输出

- 迭代报告
- A/B 测试结果
- 优化建议
