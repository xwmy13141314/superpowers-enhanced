# Idea Generation - 创意生成技能

**当以下情况时使用此 Skill**：

- 完成市场调研后，需要生成产品创意
- 用户要求"头脑风暴"、"想点子"
- 需要探索多种解决方案
- 产品需要创新、差异化
- 用户说"帮我想想办法"、"有没有更好的方案"

## 核心原则

**创意数量优先，质量在后；发散思维，延迟评判**

创意生成的目标是产生大量多样化的想法，而不是立即评判好坏。先发散后收敛，先数量后质量。

## 创意生成方法

### 方法 1: SCAMPER 技术

**SCAMPER 是一套创意思维工具：**

- **S (Substitute) - 替代**
  - 什么可以被替代？
  - 规则、材料、人员、流程...
  - 示例：用 AI 替代人工写作

- **C (Combine) - 组合**
  - 什么可以组合？
  - 功能、产品、服务...
  - 示例：写作助手 + 语法检查 + SEO 优化

- **A (Adapt) - 调整**
  - 什么可以调整？
  - 从其他领域借鉴...
  - 示例：借鉴推荐算法到写作建议

- **M (Modify) - 修改**
  - 什么可以修改？
  - 形状、属性、大小...
  - 示例：修改为移动端优先

- **P (Put to another use) - 他用**
  - 还有其他用途吗？
  - 废弃物利用...
  - 示例：写作内容转社交媒体

- **E (Eliminate) - 去除**
  - 什么可以去除？
  - 简化、瘦身...
  - 示例：去除复杂功能，专注核心写作

- **R (Reverse) - 重排/倒置**
  - 什么可以重排/倒置？
  - 顺序、因果...
  - 示例：先写大纲，再生成内容

### 方法 2: 六顶思考帽

**从不同角度思考：**

- **⚪ 白帽（数据）**
  - 我们有什么数据？
  - 市场数据、用户数据、技术数据...

- **🔴 红帽（情感）**
  - 用户的感受是什么？
  - 痛点、恐惧、期望...

- **⚫ 黑帽（批判）**
  - 可能出什么问题？
  - 风险、障碍、弱点...

- **🟡 黄帽（乐观）**
  - 最好的情况是什么？
  - 机会、优势、利益...

- **🟢 绿帽（创意）**
  - 有什么新想法？
  - 替代方案、创新点...

- **🔵 蓝帽（控制）**
  - 如何组织思考过程？
  - 计划、总结、下一步...

### 方法 3: 头脑风暴 4 步法

#### 步骤 1: 准备

- 明确问题/机会
- 设定时间限制（30-45 分钟）
- 准备工具（飞书文档、思维导图）
- 组建团队（如有）

#### 步骤 2: 发散（20-30 分钟）

**规则：**
1. 追求数量，不评判
2. 欢迎疯狂想法
3. 在此基础上构建
4. 鼓励组合改进

**提示问题：**
- "如果我们有无限资源..."
- "如果我们没有任何限制..."
- "如果我们从零开始..."
- "如果我们是用户..."

#### 步骤 3: 分类整理（5-10 分钟）

- 将相似想法归类
- 识别主题和模式
- 命名各个类别

#### 步骤 4: 收敛（5-10 分钟）

- 筛选出最有潜力的 3-5 个想法
- 评估可行性、影响力
- 准备进入验证阶段

### 方法 4: 反转问题

**从反面思考：**

- 原问题："如何提高用户留存？"
- 反转问题："如何让用户流失？"

**分析反面问题：**
- 列出所有让用户流失的方法
- 然后反转每个方法 → 留存策略

### 方法 5: 类比思维

**从其他领域借鉴：**

- "这个问题像什么？"
- "其他行业如何解决类似问题？"
- "自然界有类似的机制吗？"

**示例：**
- 写作助手 → 个人健身教练
  - 健身教练：定制计划 + 实时反馈 + 持续激励
  - 写作助手：定制风格 + 实时建议 + 持续改进

## 工作流程

### 阶段 1: 问题定义

**明确创意目标：**

- 我们要解决什么问题？
- 目标用户是谁？
- 约束条件是什么？
- 成功标准是什么？

**输出：**
- 清晰的问题陈述
- 创意简报

### 阶段 2: 创意发散

**使用多种方法生成创意：**

1. **SCAMPER** - 系统性思考
2. **六顶思考帽** - 多角度分析
3. **头脑风暴** - 团队协作
4. **反转问题** - 逆向思维
5. **类比思维** - 跨界借鉴

**目标：**
- 生成 20-30 个创意
- 记录所有想法（飞书文档）

### 阶段 3: 创意分类

**将创意分组：**

- 按主题分类
- 按类型分类（产品功能、商业模式、营销策略...）
- 按优先级分类（核心、重要、次要）

### 阶段 4: 初步筛选

**评估标准：**

- **可行性** - 技术可行吗？资源足够吗？
- **影响力** - 能解决核心问题吗？
- **创新性** - 有差异化吗？
- **用户价值** - 用户会买单吗？

**输出：**
- 筛选出 5-10 个高潜力创意
- 为每个创意撰写简要说明

### 阶段 5: 创意文档

**创建飞书文档，包含：**

1. **创意简报** - 问题定义
2. **创意列表** - 所有生成的创意
3. **筛选过程** - 评估标准和结果
4. **推荐创意** - 3-5 个最佳创意及理由
5. **下一步** - 进入 idea-validation

## 使用方法

### 触发示例

```
用户：帮我头脑风暴一下 AI 写作助手的功能
用户：我们如何差异化竞争？
用户：有什么创新方案吗？
用户：帮我想想办法解决这个问题
```

### Agent 响应流程

```
1. 确认创意目标
   - 明确要解决的问题
   - 了解约束条件

2. 执行创意生成
   - 使用多种方法
   - 生成 20-30 个创意
   - 实时记录到飞书文档

3. 分类和筛选
   - 将创意归类
   - 评估可行性
   - 筛选出 3-5 个最佳创意

4. 呈现结果
   - 展示创意列表
   - 说明推荐理由
   - 建议下一步行动
```

## 质量标准

### 创意质量检查

- [ ] 创意数量 ≥ 20 个
- [ ] 创意多样性（不同角度、不同类型）
- [ ] 创意新颖性（不是显而易见的）
- [ ] 创意可行性（不是完全不可能的）
- [ ] 评估客观性（基于标准而非偏好）

### 常见错误

❌ **避免：**
- 过早评判创意
- 只想出 3-5 个创意就停止
- 忽视"疯狂"的想法
- 只从技术角度思考
- 混淆创意生成和创意验证

✅ **应该：**
- 先发散后收敛
- 鼓励"疯狂"想法
- 多角度思考（技术、商业、用户）
- 明确区分生成和验证
- 记录所有想法
