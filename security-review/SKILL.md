# Security Review - 安全审查技能

**当以下情况时使用此 Skill**：
- 安全漏洞扫描
- 安全最佳实践
- 安全加固
- 用户说"安全审查"、"安全检查"

## 核心原则

**安全不是事后考虑**

## 工作流程

### 1. 安全扫描
- 依赖扫描（npm audit、Snyk）
- 代码扫描（SonarQube）
- 漏洞扫描（OWASP ZAP）

### 2. 漏洞分析
- SQL 注入
- XSS 跨站脚本
- CSRF 跨站请求伪造
- 认证和授权问题

### 3. 安全加固
- 输入验证
- 输出编码
- 加密（HTTPS、密码加密）
- 访问控制

### 4. 渗透测试
- 黑盒测试
- 灰盒测试
- 安全测试报告

## 输出

- 安全审查报告
- 漏洞清单
- 修复建议
