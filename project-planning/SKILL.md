# Project Planning - 项目规划技能

**当以下情况时使用此 Skill**：
- 制定项目计划
- 定义里程碑
- 资源规划
- 用户说"项目规划"、"项目计划"

## 核心原则

**计划先行，执行跟进**

## 工作流程

### 1. 项目范围定义
- 项目目标
- 项目边界
- 假设和约束

### 2. 任务分解
- WBS 工作分解结构
- 任务依赖关系
- 时间估算

### 3. 里程碑设定
- 关键里程碑
- 验收标准
- 时间节点

### 4. 资源规划
- 人力资源
- 技术资源
- 预算规划

## 输出

- 项目计划文档
- 甘特图
- 里程碑清单
